# Hot 100 题目与题解

> 说明：下面的 English/中文是对官方题意和约束的等价整理，方便在仓库内检索；完整原文、示例、约束和函数签名请点击 [README 目录](./README.md) 中的官方链接。题库页面会变化，本文件与 2026-08-30 快照一致。

## 哈希、双指针与滑动窗口

### 1. Two Sum / 两数之和（LC 1）
- **English equivalent**: Given an integer array and a target, return the indices of two distinct elements whose sum equals the target. Exactly one answer exists.
- **中文题意**：给定整数数组和目标值，返回两个不同下标，使元素和等于目标；保证恰有一个答案。
- **思路**：扫描到 `x` 时在哈希表查 `target-x`，再把 `x -> index` 放入表；先查后存可避免同一元素被使用两次。
- **复杂度**：`O(n)` 时间，`O(n)` 空间。
- **容器易错点**：`HashMap` 存的是“值到下标”，不是下标到值；重复值必须保留当前较晚下标也不影响正确性。
- **Kotlin**：`Hot100Solutions.twoSum`

### 2. Group Anagrams / 字母异位词分组（LC 49）
- **English equivalent**: Group strings that contain the same letters with the same multiplicities, in any order.
- **中文题意**：把由相同字符及其出现次数组成的字符串归为一组，组顺序任意。
- **思路**：为每个字符串建立 26 位频次数组并序列化为 key；相同 key 进入同一 `MutableList`。
- **复杂度**：`O(total characters)` 时间，`O(total characters)` 空间。
- **容器易错点**：`getOrPut` 返回的是可变列表；不要把同一个临时列表复用给多个 key。
- **Kotlin**：`Hot100Solutions.groupAnagrams`

### 3. Longest Consecutive Sequence / 最长连续序列（LC 128）
- **English equivalent**: For an unsorted array, return the length of the longest run of consecutive integers in `O(n)` time.
- **中文题意**：未排序数组中找最长连续整数序列，要求线性时间。
- **思路**：放入 `HashSet`；只从不存在 `x-1` 的起点向后扩展，每个数字至多被扩展一次。
- **复杂度**：`O(n)` 平均时间，`O(n)` 空间。
- **容器易错点**：集合去重是必要的；若对排序后的列表遍历，复杂度变为 `O(n log n)`，不符合题目进阶要求。
- **Kotlin**：`Hot100Solutions.longestConsecutive`

### 4. Move Zeroes / 移动零（LC 283）
- **English equivalent**: Move all zeroes to the end in-place while preserving the relative order of non-zero elements.
- **中文题意**：原地把所有 0 移到数组末尾，非零元素相对顺序保持不变。
- **思路**：写指针覆盖非零值，再把尾部填 0；避免额外数组。
- **复杂度**：`O(n)` 时间，`O(1)` 额外空间。
- **容器易错点**：不能用 `filter` 生成新数组后直接替换引用，因为题目要求修改传入数组本身。
- **Kotlin**：`Hot100Solutions.moveZeroes`

### 5. Container With Most Water / 盛最多水的容器（LC 11）
- **English equivalent**: Choose two vertical lines; maximize the area formed with the x-axis.
- **中文题意**：从高度数组选两条线，与 x 轴围成的容器面积最大。
- **思路**：左右指针；面积由较矮边决定，移动较高边不可能提高当前宽度下的上限，因此移动较矮边。
- **复杂度**：`O(n)` 时间，`O(1)` 空间。
- **容器易错点**：面积是 `min(height[l], height[r]) * (r-l)`，不能误用较高边；乘法建议转 `Long` 防溢出。
- **Kotlin**：`Hot100Solutions.maxArea`

### 6. 3Sum / 三数之和（LC 15）
- **English equivalent**: Return all unique triples whose values sum to zero.
- **中文题意**：返回所有和为 0 的不重复三元组，元素来自不同下标。
- **思路**：排序后固定第一个数，剩余区间使用双指针；固定值和左右指针都跳过重复项。
- **复杂度**：`O(n²)` 时间，排序空间依实现而定。
- **容器易错点**：结果中的三元组要新建 `listOf(...)`；跳过重复必须在收集后移动左右指针，否则会漏解或重复。
- **Kotlin**：`Hot100Solutions.threeSum`

### 7. Trapping Rain Water / 接雨水（LC 42）
- **English equivalent**: Given bar heights, compute how much water remains after raining.
- **中文题意**：柱状图下雨后能接多少水。
- **思路**：双指针维护两侧最大高度；较矮侧决定当前位置水位，更新该侧最大值或累加差值。
- **复杂度**：`O(n)` 时间，`O(1)` 空间。
- **容器易错点**：累计量使用 `Long` 更安全；不要把 `leftMax/rightMax` 当成当前位置高度。
- **Kotlin**：`Hot100Solutions.trap`

### 8. Longest Substring Without Repeating Characters / 无重复字符的最长子串（LC 3）
- **English equivalent**: Find the longest substring containing no repeated characters.
- **中文题意**：求不含重复字符的最长连续子串长度。
- **思路**：滑动窗口和字符最后出现位置；遇到重复字符时左端跳到 `last+1`，并保证左端不后退。
- **复杂度**：`O(n)` 时间，ASCII 情况 `O(1)` 空间。
- **容器易错点**：`IntArray(128)` 只适用于 ASCII；若题目允许更广 Unicode，应使用 `HashMap<Char, Int>`。
- **Kotlin**：`Hot100Solutions.lengthOfLongestSubstring`

### 9. Find All Anagrams in a String / 找到字符串中所有字母异位词（LC 438）
- **English equivalent**: Return start indices of substrings in `s` that are permutations of `p`.
- **中文题意**：返回 `s` 中所有与 `p` 字母计数相同的长度相同子串起点。
- **思路**：固定长度窗口维护 26 位计数，窗口每次右移一格；用 `matched` 记录满足的字符种类，避免每次比较整个数组。
- **复杂度**：`O(|s|+|p|)` 时间，`O(1)` 空间。
- **容器易错点**：结果下标是窗口左端，不是右端；窗口未达到 `p.length` 前不能收集。
- **Kotlin**：`Hot100Solutions.findAnagrams`

### 10. Subarray Sum Equals K / 和为 K 的子数组（LC 560）
- **English equivalent**: Count contiguous subarrays whose sum equals `k`; numbers may be negative.
- **中文题意**：统计和为 `k` 的连续子数组数量，数组可含负数。
- **思路**：前缀和 `prefix`；若之前出现 `prefix-k`，这些位置到当前都构成答案。哈希表存每个前缀和出现次数。
- **复杂度**：`O(n)` 时间，`O(n)` 空间。
- **容器易错点**：初始化 `map[0]=1`；这里必须存“次数”，不能只存最后一个下标（负数会使窗口法失效）。
- **Kotlin**：`Hot100Solutions.subarraySum`

### 11. Sliding Window Maximum / 滑动窗口最大值（LC 239）
- **English equivalent**: For every window of size `k`, return its maximum value.
- **中文题意**：输出每个长度为 `k` 的连续窗口最大值。
- **思路**：单调递减双端队列保存下标；队首是最大值，先删除过期下标，再删除尾部较小值。
- **复杂度**：`O(n)` 时间，`O(k)` 空间。
- **容器易错点**：Kotlin `ArrayDeque` 存下标而非值，否则无法判断过期；队列操作用 `removeFirst/addLast`，不要混用栈语义。
- **Kotlin**：`Hot100Solutions.maxSlidingWindow`

### 12. Minimum Window Substring / 最小覆盖子串（LC 76）
- **English equivalent**: Find the shortest substring of `s` containing every character of `t` with required multiplicities.
- **中文题意**：在 `s` 中找包含 `t` 全部字符（含重复次数）的最短子串。
- **思路**：右端扩张，满足需求后左端收缩；`need`/`window` 计数和 `formed` 控制覆盖条件。
- **复杂度**：`O(|s|+|t|)` 时间，`O(|s|+|t|)` 空间。
- **容器易错点**：`formed` 统计满足的字符种类，不是窗口字符总数；收缩时要先减计数再判断是否失配。
- **Kotlin**：`Hot100Solutions.minWindow`

### 13. Maximum Subarray / 最大子数组和（LC 53）
- **English equivalent**: Return the largest sum of a non-empty contiguous subarray.
- **中文题意**：求非空连续子数组的最大和。
- **思路**：Kadane：以当前位置结尾的最优和为 `max(x, previous+x)`。
- **复杂度**：`O(n)` 时间，`O(1)` 空间。
- **容器易错点**：不能把空数组默认成 0；全负数组时初值必须取第一个元素。
- **Kotlin**：`Hot100Solutions.maxSubArray`

### 14. Merge Intervals / 合并区间（LC 56）
- **English equivalent**: Merge all overlapping intervals and return a non-overlapping covering set.
- **中文题意**：合并所有重叠区间，返回互不重叠且覆盖原区间的集合。
- **思路**：按起点排序；当前区间起点不超过结果末尾终点则扩展终点，否则开启新区间。
- **复杂度**：`O(n log n)` 时间，`O(n)` 输出空间。
- **容器易错点**：排序后不要修改输入子数组；结果区间需要复制，避免后续修改影响已加入的对象。
- **Kotlin**：`Hot100Solutions.mergeIntervals`

### 15. Rotate Array / 轮转数组（LC 189）
- **English equivalent**: Rotate the array to the right by `k` steps in-place.
- **中文题意**：将数组整体向右轮转 `k` 步，要求原地完成。
- **思路**：`k %= n`；整体反转，再反转前 `k` 个和后 `n-k` 个。
- **复杂度**：`O(n)` 时间，`O(1)` 空间。
- **容器易错点**：空数组先返回；`k` 可能大于 `n`，直接取模，否则下标越界或做无效工作。
- **Kotlin**：`Hot100Solutions.rotate`

### 16. Product of Array Except Self / 除了自身以外数组的乘积（LC 238）
- **English equivalent**: Return an array where each entry is the product of all numbers except the one at that index, without division.
- **中文题意**：不使用除法，返回每个位置除自身外所有元素的乘积。
- **思路**：第一次扫描把左侧乘积写入结果，第二次从右侧乘积乘回去。
- **复杂度**：`O(n)` 时间，输出外 `O(1)` 额外空间。
- **容器易错点**：结果数组必须先初始化为 1；不能把 `result[i]` 当作原数组引用或漏掉左右乘积的单位元。
- **Kotlin**：`Hot100Solutions.productExceptSelf`

### 17. First Missing Positive / 缺失的第一个正数（LC 41）
- **English equivalent**: Find the smallest missing positive integer in `O(n)` time and constant extra space.
- **中文题意**：在线性时间、常数额外空间内找未出现的最小正整数。
- **思路**：把值 `x` 放到下标 `x-1`（只处理 `1..n`），最后第一个错位位置即答案。
- **复杂度**：`O(n)` 时间，`O(1)` 空间。
- **容器易错点**：交换条件必须包含 `nums[x-1] != x`，否则重复值会死循环；不要误把负数作为下标。
- **Kotlin**：`Hot100Solutions.firstMissingPositive`

### 18. Set Matrix Zeroes / 矩阵置零（LC 73）
- **English equivalent**: If a cell is zero, set its entire row and column to zero in-place.
- **中文题意**：若矩阵某元素为 0，则把所在行和列全部置 0，要求原地。
- **思路**：用首行/首列做标记，另用两个布尔值记录它们原本是否含 0；从第二行第二列按标记清零。
- **复杂度**：`O(mn)` 时间，`O(1)` 额外空间。
- **容器易错点**：首行首列既是数据又是标记，必须先记录 `firstRowZero/firstColZero`，否则标记会污染判断。
- **Kotlin**：`Hot100Solutions.setZeroes`

### 19. Spiral Matrix / 螺旋矩阵（LC 54）
- **English equivalent**: Return all matrix elements in clockwise spiral order.
- **中文题意**：按顺时针螺旋顺序返回矩阵所有元素。
- **思路**：维护 `top/bottom/left/right` 四个边界，每走完一条边收缩边界，并在单行/单列时避免重复。
- **复杂度**：`O(mn)` 时间，`O(mn)` 输出空间。
- **容器易错点**：第二次遍历底行和左列前要检查边界仍有效，否则中心行列会重复加入。
- **Kotlin**：`Hot100Solutions.spiralOrder`

### 20. Rotate Image / 旋转图像（LC 48）
- **English equivalent**: Rotate an `n x n` matrix 90 degrees clockwise in-place.
- **中文题意**：将方阵顺时针旋转 90 度，要求原地。
- **思路**：先沿主对角线转置，再对每行反转。
- **复杂度**：`O(n²)` 时间，`O(1)` 空间。
- **容器易错点**：转置只交换 `j > i` 的上三角；遍历全矩阵会把元素交换两次而恢复原状。
- **Kotlin**：`Hot100Solutions.rotateImage`

### 21. Search a 2D Matrix II / 搜索二维矩阵 II（LC 240）
- **English equivalent**: In a matrix sorted ascending in every row and column, decide whether `target` exists.
- **中文题意**：矩阵每行、每列均升序，判断目标值是否存在。
- **思路**：从右上角开始；当前值大于目标则左移，小于目标则下移，每步排除一行或一列。
- **复杂度**：`O(m+n)` 时间，`O(1)` 空间。
- **容器易错点**：起点必须是右上或左下这种“单调角”；从左上开始无法同时排除两个方向。
- **Kotlin**：`Hot100Solutions.searchMatrixII`

## 链表

代码中的 `ListNode`、`RandomNode` 定义在 `Hot100Solutions.kt`，字段名与 LeetCode 的 `val/next/random` 语义一致。

### 22. Intersection of Two Linked Lists / 相交链表（LC 160）
- **English equivalent**: Return the node where two singly linked lists first intersect, or `null` if they do not.
- **中文题意**：找两条单链表的第一个相交节点；不相交返回空。相交指节点对象相同，不是值相同。
- **思路**：两个指针分别走 `A+B` 与 `B+A`，长度差被抵消，最终在相交点或空节点相遇。
- **复杂度**：`O(m+n)` 时间，`O(1)` 空间。
- **容器易错点**：比较必须用引用（Kotlin `===`），不能用 `==` 比较节点值或结构。
- **Kotlin**：`Hot100Solutions.getIntersectionNode`

### 23. Reverse Linked List / 反转链表（LC 206）
- **English equivalent**: Reverse a singly linked list and return the new head.
- **中文题意**：反转单链表并返回新头节点。
- **思路**：迭代保存 `next`，把当前节点指向 `prev`，逐步推进。
- **复杂度**：`O(n)` 时间，`O(1)` 空间。
- **容器易错点**：先保存 `current.next` 再改指针；否则后续链表会丢失。
- **Kotlin**：`Hot100Solutions.reverseList`

### 24. Palindrome Linked List / 回文链表（LC 234）
- **English equivalent**: Determine whether a singly linked list reads the same forward and backward.
- **中文题意**：判断单链表正反读取是否相同。
- **思路**：快慢指针找中点，反转后半段，再逐项比较；本实现最后恢复链表。
- **复杂度**：`O(n)` 时间，`O(1)` 空间。
- **容器易错点**：奇数长度时快指针不为空，要从 `slow.next` 开始比较；不要比较节点对象而应比较值。
- **Kotlin**：`Hot100Solutions.isPalindromeList`

### 25. Linked List Cycle / 环形链表（LC 141）
- **English equivalent**: Decide whether a linked list contains a cycle.
- **中文题意**：判断链表是否存在环。
- **思路**：Floyd 快慢指针；慢一步、快两步，若相遇则有环。
- **复杂度**：`O(n)` 时间，`O(1)` 空间。
- **容器易错点**：循环条件必须先检查 `fast?.next`，否则访问空指针；快慢指针不能从同一推进步长开始。
- **Kotlin**：`Hot100Solutions.hasCycle`

### 26. Linked List Cycle II / 环形链表 II（LC 142）
- **English equivalent**: Return the node where a cycle begins, or `null` if no cycle exists.
- **中文题意**：返回环的入口节点，无环返回空。
- **思路**：快慢指针相遇后，一个指针回到头部，两个指针每次一步；再次相遇处即入口。
- **复杂度**：`O(n)` 时间，`O(1)` 空间。
- **容器易错点**：入口判断仍是引用相等（`===`）；相遇后不能直接把相遇点当入口。
- **Kotlin**：`Hot100Solutions.detectCycle`

### 27. Merge Two Sorted Lists / 合并两个有序链表（LC 21）
- **English equivalent**: Merge two ascending linked lists into one ascending list by reusing nodes.
- **中文题意**：将两个升序链表合并为一个升序链表，可复用原节点。
- **思路**：哑节点加双指针，每次接入较小节点，最后接上剩余链。
- **复杂度**：`O(m+n)` 时间，`O(1)` 额外空间。
- **容器易错点**：哑节点只作前置指针，返回 `dummy.next`；返回 `dummy` 会多出一个值为 0 的伪节点。
- **Kotlin**：`Hot100Solutions.mergeTwoLists`

### 28. Add Two Numbers / 两数相加（LC 2）
- **English equivalent**: Add two numbers represented by reverse-order digit lists and return the sum in the same format.
- **中文题意**：两个逆序数字链表表示非负整数，返回逆序和链表。
- **思路**：逐位相加，维护 `carry`；任一链表或进位未处理完都继续循环。
- **复杂度**：`O(max(m,n))` 时间，`O(1)`（不计输出）空间。
- **容器易错点**：不要在 `l1 != null && l2 != null` 时提前结束，否则会漏掉长链尾部或最终进位。
- **Kotlin**：`Hot100Solutions.addTwoNumbers`

### 29. Remove Nth Node From End of List / 删除链表的倒数第 N 个结点（LC 19）
- **English equivalent**: Remove the n-th node from the end of a list in one pass and return the head.
- **中文题意**：一次遍历删除倒数第 `n` 个节点并返回头节点。
- **思路**：哑节点起步，快指针先走 `n` 步，然后快慢一起走到快指向尾部。
- **复杂度**：`O(n)` 时间，`O(1)` 空间。
- **容器易错点**：使用哑节点统一处理删除头节点；间距是 `n`，循环条件要让 `slow` 停在待删节点前一个。
- **Kotlin**：`Hot100Solutions.removeNthFromEnd`

### 30. Swap Nodes in Pairs / 两两交换链表中的节点（LC 24）
- **English equivalent**: Swap every adjacent pair of nodes without changing node values.
- **中文题意**：两两交换相邻节点，不能只交换节点值。
- **思路**：哑节点指向当前组前驱，保存 `first/second`，重连 `prev -> second -> first -> next`。
- **复杂度**：`O(n)` 时间，`O(1)` 空间。
- **容器易错点**：先判断 `prev.next` 和 `prev.next.next` 均非空；交换指针顺序错误会形成环或丢链。
- **Kotlin**：`Hot100Solutions.swapPairs`

### 31. Reverse Nodes in k-Group / K 个一组翻转链表（LC 25）
- **English equivalent**: Reverse nodes in contiguous groups of size `k`; leave a shorter final group unchanged.
- **中文题意**：每 `k` 个节点一组反转，不足 `k` 个的尾组保持原样。
- **思路**：先从 `groupPrev` 探测第 `k` 个节点，存在才原地头插法反转这一段。
- **复杂度**：`O(n)` 时间，`O(1)` 空间。
- **容器易错点**：探测指针要从组前驱开始走 `k` 次；不足一组时必须立即停止，不能部分反转。
- **Kotlin**：`Hot100Solutions.reverseKGroup`

### 32. Copy List with Random Pointer / 随机链表的复制（LC 138）
- **English equivalent**: Deep-copy a list where each node has `next` and an arbitrary `random` pointer.
- **中文题意**：深拷贝带 `random` 任意指针的链表，副本节点不能与原节点共享。

- **中文题意**：以 `O(n log n)` 时间排序单链表，要求低额外空间。
- **思路**：快慢指针拆分，递归归并两个有序链表。
- **复杂度**：`O(n log n)` 时间，递归栈 `O(log n)`。

- **中文题意**：设计固定容量缓存，读写均为 `O(1)`，超容量淘汰最久未使用项。

- **中文题意**：在升序数组中查找目标；不存在时返回保持有序的插入下标。
- **思路**：标准 lower bound：维护半开区间 `[left,right)`，收缩到第一个 `>= target` 的位置。
- **复杂度**：`O(log n)` 时间，`O(1)` 空间。

- **English equivalent**: Search a matrix whose rows are sorted and each row starts after the previous row ends.
- **中文题意**：矩阵每行升序且下一行首值大于上一行末值，判断目标是否存在。
- **思路**：把矩阵视为长度 `m*n` 的一维有序数组，二分后用 `index / n`、`index % n` 映射坐标。
- **复杂度**：`O(log(mn))` 时间，`O(1)` 空间。

- **中文题意**：在升序数组中找目标值的起止下标，不存在返回 `[-1,-1]`。
- **思路**：两次 lower/upper bound；第一次找第一个 `>= target`，第二次找第一个 `> target`，右端减一。
- **复杂度**：`O(log n)` 时间，`O(1)` 空间。
- **容器易错点**：边界函数返回插入位置而非元素下标，使用前要检查是否越界及值是否等于目标。

### 66. Search in Rotated Sorted Array / 搜索旋转排序数组（LC 33）
- **English equivalent**: Search a target in a rotated strictly increasing array in `O(log n)`.
- **中文题意**：在无重复、旋转后的升序数组中以对数时间查找目标下标。
- **思路**：每轮至少一半有序；判断目标是否落在有序半边，再舍弃另一半。

### 67. Find Minimum in Rotated Sorted Array / 寻找旋转排序数组中的最小值（LC 153）
- **English equivalent**: Return the minimum value in a rotated strictly increasing array.
- **中文题意**：返回无重复旋转升序数组的最小值。
- **思路**：比较 `nums[mid]` 与 `nums[right]`；前者较小说明最小值在左侧含 mid，否则在右侧。
- **复杂度**：`O(log n)` 时间，`O(1)` 空间。

### 69. Valid Parentheses / 有效的括号（LC 20）

- **中文题意**：判断只含三种括号的字符串是否正确闭合、嵌套。

### 70. Min Stack / 最小栈（LC 155）
- **English equivalent**: Design a stack supporting push, pop, top, and retrieving the minimum in `O(1)`.
- **中文题意**：设计支持入栈、出栈、查看栈顶和常数时间取最小值的栈。
- **思路**：数据栈外维护最小值栈；每次压入当前最小值，出栈同步弹出。

- **思路**：单调递减栈存下标；当前温度更高时不断弹栈并计算距离。

- **English equivalent**: Compute the minimum insertions, deletions, and substitutions to transform one string into another.
- **中文题意**：用插入、删除、替换三种操作，把一个字符串变为另一个所需的最少步数。
- **思路**：`dp[i][j]` 表示前缀转换代价；字符相等沿对角线，否则取删除、插入、替换三者最小加 1。
- **复杂度**：`O(mn)` 时间，`O(mn)` 空间。
- **容器易错点**：初始化 `dp[i][0]=i`、`dp[0][j]=j`；只填内部格会导致空前缀转移错误。
- **Kotlin**：`Hot100Solutions.minDistance`

### 96. Single Number / 只出现一次的数字（LC 136）
- **English equivalent**: Every element appears twice except one; return the single element using linear time and constant space.
- **中文题意**：除一个元素外其余均出现两次，找出只出现一次的元素。
- **思路**：异或满足交换律、结合律且 `x xor x=0`、`x xor 0=x`。
- **复杂度**：`O(n)` 时间，`O(1)` 空间。
- **容器易错点**：不需要 `HashSet`；若使用集合会额外占用线性空间且容易误删重复值。
- **Kotlin**：`Hot100Solutions.singleNumber`

### 97. Majority Element / 多数元素（LC 169）
- **English equivalent**: Return the value appearing more than `n/2` times; such a value is guaranteed.
- **中文题意**：返回出现次数严格超过数组长度一半的元素，保证存在。
- **思路**：Boyer-Moore 投票，候选计数为 0 时换候选，相同加一、不同减一。
- **复杂度**：`O(n)` 时间，`O(1)` 空间。
- **容器易错点**：题目保证多数元素时无需二次验证；若题目不保证存在，投票后必须再次计数确认。
- **Kotlin**：`Hot100Solutions.majorityElement`

### 98. Sort Colors / 颜色分类（LC 75）
- **English equivalent**: Sort an array containing only 0, 1, and 2 in-place in one pass.
- **中文题意**：原地将只含 0、1、2 的数组排序，要求一次遍历、常数空间。
- **思路**：荷兰国旗三指针：`[0,low)` 为 0，`[low,mid)` 为 1，`(high,n)` 为 2。
- **复杂度**：`O(n)` 时间，`O(1)` 空间。
- **容器易错点**：交换 2 后 `mid` 不立即加一，因为换来的元素尚未检查；交换 0 后才可同时推进 `low/mid`。
- **Kotlin**：`Hot100Solutions.sortColors`

### 99. Next Permutation / 下一个排列（LC 31）
- **English equivalent**: Rearrange numbers into the lexicographically next greater permutation, or the smallest order if none exists.
- **中文题意**：把数组变为字典序恰好更大的下一个排列；若不存在则变为最小升序排列。
- **思路**：从右找首个下降点 `i`，从右找刚好大于 `nums[i]` 的 `j` 交换，再反转后缀。
- **复杂度**：`O(n)` 时间，`O(1)` 空间。
- **容器易错点**：后缀交换后是降序，必须反转而不是排序；找 `j` 时从右向左可保证选到最小增量。
- **Kotlin**：`Hot100Solutions.nextPermutation`

### 100. Find the Duplicate Number / 寻找重复数（LC 287）
- **English equivalent**: In an array of `n+1` integers in `[1,n]`, find the only repeated value without modifying the array and with constant space.
- **中文题意**：长度 `n+1`、值域 `1..n` 的数组只有一个重复值（可重复多次），不能修改数组且只能常数空间。
- **思路**：把 `i -> nums[i]` 看作链表，重复值是环入口；Floyd 两阶段求环入口。
- **复杂度**：`O(n)` 时间，`O(1)` 空间。
- **容器易错点**：这是“下标访问形成的隐式图”，不是排序/集合题；快慢指针比较的是索引位置，不能把数组元素当节点对象。
- **Kotlin**：`Hot100Solutions.findDuplicate`
